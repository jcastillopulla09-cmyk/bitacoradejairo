# assets/

Coloca aquí el logo oficial con este nombre exacto:

    assets/logo-bitacora.png

Recomendado: PNG cuadrado de 512 × 512 px (se recorta en círculo automáticamente).
Mientras el archivo no exista, el sitio muestra un monograma SVG «BJ» como respaldo
(barra de navegación, favicon, tarjeta «Acerca» y pie), nunca una imagen rota.
